This repository contains my code and notes from working through **[Build a Large Language Model (From Scratch)](https://www.manning.com/books/build-a-large-language-model-from-scratch)** by Sebastian Raschka (Manning).

The book walks through building a GPT-style large language model step by step in PyTorch, without relying on high-level LLM libraries. It covers preparing and tokenizing text data, implementing attention mechanisms, assembling a full GPT architecture, pretraining it on unlabeled text, and fine-tuning it for tasks like text classification and instruction following. I'm following along chapter by chapter, writing the code myself to understand how each part of a modern LLM works.

All credit for the original material goes to Sebastian Raschka. The official code repository for the book is [rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch).
